# Security policy

Roblox Viewer runs a local web server and can expose it through a tunnel. It
shows the contents of your screen, so security reports are welcome.

## Reporting a vulnerability

Please **do not open a public issue** for security problems. Use GitHub's
private reporting flow instead:

1. Open the **Security** tab of this repository.
2. Choose **Advisories > Report a vulnerability**.

Useful reports include an authentication bypass, a way to read a stream
without the key, a leaked key, or a capture that includes windows other than
the selected Roblox windows.

Only the latest release is supported with security fixes.
